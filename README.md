# Lex Technologies Website

This is a fast, static marketing site for **Lex Technologies** (cybersecurity).

## Preview locally

Option 1: Open `index.html` directly in a browser.

Option 2: Run a tiny local server from this folder:

```powershell
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Customize

Update site details in:

- `assets/site.js` (domain + contact/security emails)
- `robots.txt` and `sitemap.xml` (domain URLs)
- `.well-known/security.txt` (security disclosure contact)
